# ClinicFlow

ClinicFlow is a real-time clinic queue and appointment management SaaS that helps clinics reduce patient waiting time through live queue tracking and appointment scheduling.

## Features

- JWT Authentication
- Doctor & Patient Registration
- Appointment Management
- Real-time Queue Tracking
- Subscription Management
- Secure REST API

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- React
- TypeScript
- JWT

## Installation

```bash
git clone https://github.com/your-username/patientflow.git
cd patientflow
npm install
npm run dev
```
